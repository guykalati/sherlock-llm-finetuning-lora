The experiment I wanted to check

Does adapting the MLP as well as attention improve validation loss under the same example and step budget? I held the data, seed and starting model fixed. The larger adapter arm also has more parameters, so this is a practical comparison rather than an equal-capacity experiment.

The implementation that matters

The runner saves and reloads the actual CPT adapter before SFT. It verifies the chat prefix and masks prompt labels, so SFT trains on the assistant response. Hashes and an independent scoring script connect the result to the code and data.

The next domain needs a better corpus

Separate biomedical preparation work

A versioned cardiovascular review queue

I prepared source identity, licensing, notice and benchmark-overlap checks for a 5,403-article review queue. After development reservations, 5,249 entries still need scientific admission checks. No article in this queue has been admitted to training.

A screening method I rejected

The 24-paper Qwen pilot matched both draft topic and evidence-group labels on only 3 cases. Larger-model checks still misread background-only sources. I kept these failures in the record instead of turning the raw token inventory into a training claim.
